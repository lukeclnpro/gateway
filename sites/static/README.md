# Sites statiques

Pour ajouter un site statique :

1. Crée un dossier dans `sites/static/`.
2. Mets-y `index.html`.
3. Ajoute tes fichiers CSS, JS, images, etc.
4. Dans `menu.py`, utilise "Ajouter un site statique".

Tu peux aussi fournir directement le chemin absolu d'un dossier contenant
`index.html`.
